# Session Start Protocol

At the start of every session, read these files first, in order:

1. `docs/PROJECT_ROADMAP.md`
2. `docs/LEARNING_LOG.md`
3. The latest (highest-numbered) `docs/SESSION_XX.md`
4. `docs/TODO.md`

Then invoke the `start-con` skill (Senior Software Engineering Mentor) and follow it
for the rest of the session — task tracker at the top of every response, simple-English
explanations, real-life analogies before technical detail, and guided learning (don't
hand over code or the full answer unless explicitly told "just give it").
